# 账号余额

在 Web 界面的侧边栏底部、账号入口（头像与昵称那一行）正上方新增一行余额，登录后直接显示 DeepSeek 账号的充值余额。

## 使用

- 登录 DeepSeek 账号后，余额行出现在侧边栏左下角账号入口的正上方，与账号行使用相同的左右内缩。
- 点击余额行立即重新读取余额；若已有一次读取正在进行，会复用它而不是重复请求。
- 页面可见时每 3 分钟自动刷新一次；窗口重新获得焦点或从后台切回时也会刷新，距上次尝试不足 60 秒则跳过（失败后同样适用，避免反复重试）。
- 打开设置或从充值页返回时，内置账号插件会发出刷新事件，余额随之更新；重新登录、切换账号或连接恢复时也会重新读取。

## 显示规则

- 只显示充值余额（正常钱包），按币种保留两位小数并使用对应货币符号；多个钱包以 ` · ` 分隔。
- 数额来自服务端的十进制字符串，不经过二进制浮点：正数截断到分，正数不足 0.01 时显示 `<¥0.01`，负数按四舍五入到分且最小显示 0.01，零显示 `¥0.00`。
- 赠送余额（赠金）不占主行，鼠标悬停余额行时会在提示中列出。
- 未登录、账号凭据未存储或没有账号访问权限时，整行不渲染。
- 侧边栏收起为窄栏或抽屉未展开时，余额行不渲染。
- 读取失败时保留上次成功的金额（数值转为次要色），并在悬停提示中标注「上次刷新失败」；从未成功读取时显示 `—`，悬停提示与无障碍名称为「暂不可用 · 点击重试」。
- 切换账号时，上一个账号的金额会立即清空，不会显示在新账号名下。

## 数据与隐私

- 余额来自 DeepSeek Platform 的账号钱包接口，通过 Host 的 `account` Remote 读取；凭据只保存在 Host 侧，界面不会接触令牌。
- 插件不上报任何数据，也不写入会话日志。
- 关闭插件后余额行立即消失，其他界面不受影响。

## 位置说明与限制

余额行使用侧边栏底部为插件预留的追加动作位（`sidebar.footer.action`），该区域在账号入口正上方。账号入口本身由内置账号插件独占，无法在不替换它的前提下塞入内容，因此余额显示为紧邻其上的一行，而不是头像行内的徽标。

该追加动作位是横向排列的：当同时存在动态 Cordis 插件面板（左下角、账号入口上方的「Cordis Plugin」行）时，该行会占满整行宽度并不收缩，余额行会被挤到零宽而不可见。此时余额仍在后台读取，关闭动态 Cordis 插件或让其面板行消失后即恢复显示。

## 修改刷新节奏

`client.js` 顶部的 `REFRESH_INTERVAL_MS`（默认 180000 毫秒）与 `MIN_ATTEMPT_GAP_MS`（默认 60000 毫秒）控制自动刷新间隔与最小尝试间隔；修改后需重启应用或重新加载插件以载入新的客户端代码。

# 侧边聊天

侧边聊天会把你正在阅读的对话分叉成一个独立的会话，并在右侧边栏打开。它相当于 Codex 的 side conversation：你可以在这条侧边线里追问、起草方案或与智能体讨论，而侧边线产生的消息和工具调用不会进入主对话的上下文。

## 功能

- 在对话页头右侧增加一个气泡按钮。
- 以“最近一个已完成的回合”为边界分叉当前会话，复用 Chat 页脚“分叉”所用的独立分叉能力。
- 在右侧边栏以标签页打开分叉，内部使用共享的 Conversation 主体，拥有自己的输入框、模型选择和对话记录。
- 主会话保持原样：侧边聊天是另一个拥有独立日志的会话。

## 使用方式

1. 打开一个至少完成过一轮对话的会话。
2. 点击页头右侧的气泡按钮。
3. 在右侧边栏的标签里继续讨论。
4. 再次点击同一按钮会显示已经打开的侧边聊天；关闭标签后再点击，会从主对话的最新状态重新分叉。

## 限制

- 分叉边界始终是最近一个已完成的回合；正在进行中的回合不会被复制，即使主对话仍在继续输出。
- 侧边聊天是临时的分叉，而不是第二条永久会话。关闭标签会归档这个分叉，并停止其中仍在进行的工作，使它不会留在会话列表里。如需继续使用，可在会话列表的“归档”筛选中取消归档。
- 当前版本不会把侧边聊天的内容合并回主对话。
